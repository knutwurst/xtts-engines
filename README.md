# XTTS Studio Pro - Model & Tool Mirror

Public mirror of model and tool assets used by XTTS Studio Pro.

This mirror exists to ensure long-term availability of the engine checkpoints even if upstream sources change, become gated, get rate-limited or are taken down. The app can be configured in Diagnostics -> Model Source to download either from the original upstream or from this mirror; the default is the original upstream source.

All files are distributed via GitHub Releases. Each release contains:

- The original model files, unmodified, byte-for-byte identical to upstream.
- A `SHA256SUMS` manifest for integrity verification.
- A `LICENSE` and `ATTRIBUTION` file copied from the original source when provided upstream.

This file is generated by `tools/mirror_engines.sh`. Set `XTTS_MIRROR_README_PATH` if you want the script to write directly into a checked-out mirror repository's `README.md`.
